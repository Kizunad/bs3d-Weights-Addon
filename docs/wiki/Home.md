# BS3D Weights Addon

适用：未发布的 `0.1.0-SNAPSHOT`。Addon 协议 v1，Framework wire v2，Minecraft 1.20.1、Fabric、Java 17。

服务端读取真实库存并递归计算重量，客户端只格式化服务端快照。没有负重上限、减速或其他惩罚。原版 HUD 的隐藏规则继续由宿主决定；附属不会增加常驻 HUD 或新的大面板。
